# 产品形态逆向、竞品对比与「稳健收益」迭代

日期：2026-10-14。北极星：**一个小白投资者的稳健型投资收益**。

证据分三级，正文里逐条标注，读的时候请区别对待：

- **[REA]** 用 REA 对运行中的产品和竞品公开页面实测取证，可复现。
- **[检索]** 公开搜索结果。其中大量是厂商博客或联盟营销文章，数字相互矛盾处会注明，**不要当事实引用**。
- **[推断]** 基于以上证据的判断，可以被推翻。

---

## 0. 结论先行

1. **产品形态**：Crypto Radar 目前是一个**交易员终端**——三栏、满屏指标、围绕「某个币接下来怎么走」组织。
   它完全没有「用户自己的钱」这个概念：没有持仓、没有目标、没有风险预算。[REA]
2. **它最大的资产是诚实**：四次回测都没测出方向预测力，且界面把这件事摊开给用户看
   （研判命中 48%，落后「全猜上涨」10 个百分点）。[REA + 自家数据]
3. **这与北极星冲突**：稳健收益靠的不是猜对涨跌，而是**别亏过头、别在恐慌或兴奋时乱操作、按规则持续做**。
   一个大多数时候说「震荡」的预测，对小白几乎没有决策价值，而满屏「看空」标签反而可能诱发杀跌。[推断]
4. **竞品里没有人同时做到「面向小白 + 风险优先 + 本地隐私」**：
   组合追踪类（CoinStats）要你连账户；链上研究类（Glassnode）面向机构；传统金融的机器人投顾
   （Betterment、Wealthfront）有对的范式，但不碰加密。这是空位。[REA + 推断]
5. **本轮迭代**：新增**稳健驾驶舱**并设为首页，原看板完整保留在 `/radar`。
   核心是「**先问风险，再谈机会**」：你先写下最多能亏多少，系统反推最多该持有多少加密资产，
   每天只回答一个问题——「按我自己的规则，今天要不要做点什么」（大多数日子：不用）。

## 1. 本产品的形态（REA 逆向）

### 1.1 取证方法

| 目的 | REA 工具 | 做了什么 |
|---|---|---|
| 运行时行为 | `capture_browser_scenario`（启动独立 profile 的 Chromium） | 加载首页，逐个点开 6 个标签页，记录网络请求与 WebSocket，取界面树与截图 |
| 打包产物 | `analyze_web_bundle`（连接模式） | 静态解析 8 个脚本，得到路由、接口候选、依赖指纹（脚本只解析、不执行） |
| 页面与存储 | `inspect_web_page`（连接模式） | DOM 规模、无障碍树、本地存储清单 |

### 1.2 形态清单

**界面**：单页应用，`routes` 为空；三栏——左栏自选，中栏 TradingView lightweight-charts 图表加衍生品条与「趋势预判」表，
右栏 6 个标签页（技术面 / 预测 / AI 研判 / 对比 / 宏观 / 告警）。[REA]

**运行时画像**（打开首页 6 秒内）：[REA]

- **18 次 API 请求 + 1 条 WebSocket**（`wss://data-stream.binance.vision`，订阅 5 个币的 miniTicker）。
- 有冗余：`/api/market/tickers` 被请求 3 次（参数顺序不同），`/api/market/routes` 2 次。
- **页面一挂载就请求 `/api/news/digest`，它会触发一次付费的 LLM 调用**
  （在本地假模型上观测到 `max_tokens=4000` 的请求与首页加载同时发生）。
- 首页所有请求只去本机和币安镜像，**没有第三方分析脚本**（REA 的网络事件）。

**打包产物**：8 个脚本共约 713 KB；Next.js（Turbopack）+ React；客户端接口候选共 13 个
（行情、研判、宏观、情绪、告警、链上、预测，以及一条直连 OKX 的 WebSocket）。[REA]

**用户状态**：全新 profile 下 localStorage / IndexedDB 为空，用户状态只有自选列表。
**接口候选里没有任何持仓、计划、组合、风险预算相关的端点**——这是「缺失的能力」的直接证据。[REA]

### 1.3 对小白的体验审计

- **首屏术语密度**：RSI(14)、MACD 柱、MA20/50/200、%B、ATR%、量比、资金费率、未平仓量、EFFR、
  P25–P75、名义盈亏比……全部不带解释。[REA]
- **首屏出现方向性标签**：趋势预判表给出「看空 / 看空 / 震荡」。对一个已经在回撤中的小白，
  这是最容易促成杀跌的信息。[REA + 推断]
- **默认答案永远是「看点什么」**：6 个标签页、每个都在邀请你研究，没有一处说「你今天可以不管它」。[推断]

### 1.4 信号质量（项目自己的数据，这是它的特色）

| 来源 | 结果 |
|---|---|
| AI 研判（34 条，31 条已检验）[REA 面板 + `data/analyses.json`] | 命中 48%；基线「全猜震荡」42%、「全猜上涨」58%（落后 10pt）；85% 的结论是「震荡」 |
| 技术走势预测（运行中服务里的未提交功能）[REA] | 方向命中 25.9%（7/27），相对「价格不变」基线 −25.6% |
| README / ROADMAP 回测 | 规则引擎 30.2% vs 全猜震荡 51.9%；多周期共振、主动成交流、稳定币供应变化均无预测力 |

样本小、窗口重叠，**只能当作方向性参考**；但它与「别把预测当决策依据」的结论一致，且产品没有隐瞒。

### 2.3 空位

把「小白 + 风险优先 + 本地隐私」放在一起看，**没有竞品同时满足**：

- 加密向的产品都以**行情或数据**为入口，不是以**用户的底线**为入口。[REA + 推断]
- 做对了「目标 → 概率区间 → 纪律」范式的是传统金融机器人投顾，但它们不覆盖加密资产。[REA + 推断]
- 隐私：加密向竞品多要求连接账户，或首页带分析脚本；本产品首页零第三方脚本。[REA]

## 3. 北极星拆解：「稳健收益」到底由什么决定

不能承诺的事先说清：**没有任何工具能保证稳健收益，更不能保证不亏**。这个产品能做的，
是影响下面三个**行为与风险**变量，而不是预测价格。

| 变量 | 证据 | 含义 |
|---|---|---|
| **行为差**（买卖时机拖累收益） | Morningstar《Mind the Gap》2026 版：美国基金投资者 10 年年化 8.7% vs 基金本身 9.9%，差 1.2pp；波动最大的基金差 −2.1pp，最小的 −0.4pp；**现货比特币 ETF 约每年 14pp**（追涨杀跌）[检索：二手报道，请以原报告为准] | 波动越大，人越容易做错决定。**最大的敌人是自己** |
| **一次性 vs 定投** | Vanguard 研究（二手转述）：一次性投入约三分之二的时间更优（1976–2022 约 68%），但定投在下跌市里更好，约 69% 的时候优于一直拿现金 [检索] | 定投**不是收益最大化工具，是行为工具**：让买入与行情无关 |
| **回撤的量级** | BTC 历轮熊市约 −75%~−85%（iShares 称三次最大回撤平均约 −80%）[检索]；币安镜像日线能回溯的 ~2.7 年里最大回撤 −53%，**当前距一年高点约 −27%（距这段历史最高收盘约 −33%）** [REA + 实测] | 小白最大的风险不是涨得慢，是**亏到拿不住而割肉** |
| **仓位大小** | CoinShares / WisdomTree 等：小比例配置对组合整体回撤影响有限 [检索：均为发行方资料，窗口短，有利益相关] | 决定风险的首先是**占多大比例**，其次才是买哪个币（但也有资料称，从股票里划出 5% 买 BTC 会明显抬高平均回撤——Calamos，同样是发行方资料） |

由此得到四条产品原则（也是这一轮实现的约束）：

1. **先问风险，再谈机会**：用户先写底线，配置由底线反推，而不是先选币。
2. **默认动作是什么都不做**：没有规则被触发就明说「今天没有需要做的事」。
3. **只做用户自己计划的执行者**：每条提示都来自用户设定的规则，并附「为什么」。不荐股、不预测。
4. **财务数据只在本机**：手动录入，不要 API Key；并因此新增本机访问保护。

## 4. 差距分析

| 稳健目标所需的能力 | 迭代前 | 竞品 | 本轮 |
|---|---|---|---|
| 组合视角（持仓、占比、盈亏） | 无 | CoinStats（需连账户） | ✅ 手动录入，本机存储 |
| 风险量化（最大回撤、最差 30 天、压力测试） | 仅单币 ATR | Betterment 的概率区间（传统资产） | ✅ 历史回放 + 情景压力 |
| 底线 → 配置上限（风险预算） | 无 | 无（加密向） | ✅ 由底线反推，留 20% 安全垫 |
| 定投 / 再平衡纪律 | 无 | Betterment、Wealthfront 自动化 | ✅ 提醒 + 用新资金补低配（**不自动交易**） |
| 行为护栏（冷静期、预案） | 无 | 无 | ✅ 大波动日提醒冷静 24 小时；回撤触及底线时展示用户事先写好的预案 |
| 小白语言 | 术语密集 | Betterment 简洁 | ✅ 术语折叠解释；首页不放方向性标签 |
| 诚实的信号质量 | ✅（特色） | 多为营销 | 保持，并在市场环境区明说「这些指标不能预测涨跌」 |
| 隐私 | ✅ 本机 | 多要账户授权 | ✅ 强化：本机访问保护、0600 权限、纳入每日备份 |

## 5. 本轮已实现（稳健驾驶舱 v1）

**首页 `/` = 稳健驾驶舱**；原看板移到 `/radar`，两边都有入口。若不想改首页，把 `src/app/page.tsx` 改回渲染 `Dashboard` 即可。

- **今天要做什么**：规则引擎，按严重程度排序；每条带「为什么」。规则有：熊市情景亏损超过 / 接近底线、
  回撤触及 / 接近底线（并展示用户事先写好的预案）、配置偏离、定投日（按目标配置用新资金补低配）、
  大波动日（24 小时涨跌超过 3 倍日标准差 → 冷静 24 小时）。没有触发时输出「今天没有需要做的事」。
- **我的底线**：首次使用是引导——先选「最多能亏多少」（保守 15% / 稳健 25% / 积极 40% / 自填），
  系统**反推**目标配置并实时检查是否自洽。定投、再平衡容忍带、预案都在这里。
- **我的组合**：手动录入持仓；实时估值；与目标的偏离。
- **风险体检**：① 历史回放（按当前比例，最大回撤、当前回撤、最差 30 天、年化波动）；
  ② 压力测试（BTC 再跌 30% / 50% / 75%，其他币按实测 beta 联动）；③ 风险预算。
- **市场环境**：只描述（距一年高点、距 200 日线、波动所处分位、恐惧贪婪），不配涨跌配色。

关键的计算口径：

- 熊市基准取 **BTC −75%**（历轮熊市量级的偏温和一端）。**这是情景，不是预测**。
- 反推配置时把熊市亏损控制在底线的 **80% 以内**（安全垫）：基准本身是假设，下一次可能更深。
- 稳定币按 1 美元计，界面会提醒脱锚与平台风险。

工程上：计算层全是纯函数（`src/lib/steady/`），120 余项单测覆盖回撤 / beta / 反推配置（属性测试扫过 5%~80% 的所有底线）/
定投日程 / 规则引擎 / 访问保护 / 存储（原子写、损坏不覆盖）。

## 6. 路线

| 阶段 | 内容 | 为什么 |
|---|---|---|
| **v2：行为实验室** | 用真实日线对比「按计划定投 / 一次性买入 / 追涨杀跌」的终值、最大浮亏、最差 30 天；明示一次性投入历史上更常赢（Vanguard），但定投让回撤更好承受 | 让用户**亲眼看见**行为差，而不是被说教；对应 Mind the Gap 的证据 |
| v2：风险提醒推送 | 把「熊市情景超限 / 回撤触及底线 / 配置偏离」接到现有告警通道（企业微信、钉钉、飞书、Telegram） | 不必每天打开页面就能被及时提醒——同时也减少盯盘 |
| v2：操作日记与计划遵守度 | 记录每次计划内 / 计划外操作，统计「遵守度」 | 北极星的可度量代理指标 |
| v2：稳定币脱锚监测、手机布局、首页请求合并（去掉挂载即调 LLM） | 见 1.2 的冗余 | 「稳定币 = 现金」是本轮的一个假设，应当被监控 |
| v3：目标驱动 | 目标金额 + 期限 → 达成概率区间（类 Betterment），用历史重采样并明示局限 | 把「稳健」从「别亏」推进到「走向一个目标」 |

**如何衡量这个迭代有没有用**（它不该用「预测准不准」来衡量）：计划遵守度、实际最大回撤相对底线的比值、
计划外操作次数。前两项依赖 v2 的日记功能，在那之前无法度量——这是一个诚实的缺口。

## 7. 局限与声明

- **竞品信息的完整度**：6 家站点被拦截或崩溃，只能依据 [检索]；5 家完成的也只取了首页 / 公开页，
  看不到登录后的产品。价格与功能可能已变，请以官网为准。
- **检索来源的质量**：多为厂商博客与联盟文章，数字互相矛盾处已注明，**不要把它们当事实引用**。
- **风险数字的口径**：历史回放只有 ~2.7 年，没有覆盖真正的熊市；压力测试是假设；beta 来自最近一年的共同历史，
  样本不足时退回默认估计值并在界面标注。
- **这不是投资建议**：我不是持牌投顾。驾驶舱只是你自己设定的规则的计算器，
  「稳健」不等于「保本」。加密资产历史上多次出现 75% 以上的回撤。
